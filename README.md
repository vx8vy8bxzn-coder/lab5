В этой работе я изучала создание графических интерфейсов с помощью Tkinter и PyQt5.

Задания средней сложности:

- №9 — цветная панель, которая меняет цвет по кнопке;
- №1 — окно с кнопкой «Привет»;
- №6 — прогрессбар с пошаговым заполнением.

Задания повышенной сложности:

- №9 — приложение PyQt5 с таблицей книг;
- №2 — рисование прямоугольников и овалов мышью.

Для приложения с таблицей нужно установить PyQt5:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Примеры запуска из корня репозитория:

```bash
python3 color_panel.py
python3 hello_button.py
python3 progress_bar.py
python3 shape_drawing.py
python3 pyqt_table.py
```

В первом окне кнопка переключает цвета панели. Во втором после нажатия появляется приветствие. Прогрессбар заполняется по 10%, а после 100% начинается заново. В редакторе нужно выбрать фигуру и цвет, затем протянуть мышь по белому холсту. В PyQt-приложении открывается сортируемая таблица книг.

Для проверки заданий я добавила 27 тестов. После установки зависимостей все они запускаются из корня репозитория:

```bash
python3 -m unittest discover -s tests -v
```
